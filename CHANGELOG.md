# Changelog

## 1.3.0 - 2026-10-12

- Add separate refresh intervals for the process list and for CPU and memory
- Add manual refresh button to the PM2 view header

## 1.2.0 - 2026-03-12

- Add bulk start, restart, and stop buttons
- Remove manual refresh button
- Fix process actions targeting wrong process when names are not unique

## 1.1.0 - 2026-03-11

- Instant status update on start/stop/restart
- Action buttons hide during transitions (launching, stopping)
- UI reverts if a pm2 command fails

## 1.0.0 - 2026-03-10

- Initial release
- View PM2 processes in Explorer panel
- See process status, CPU and memory usage
- Open logs in integrated terminal
- Start, stop, and restart processes from inline actions
- Auto-refresh every 5 seconds
- Manual refresh from view header
